# Salary Analysis Dashboard - Submission Package Guide

This folder contains all required assignment deliverables for your **Salary Analysis Dashboard** activity submission.

---

## 📁 Package Deliverables Included

1. **Dataset (`salary_analysis_dataset.csv`)**
   - 1,050 preprocessed, clean records covering global data & tech roles.
   - Includes fields: `Employee_ID`, `Work_Year`, `Experience_Level`, `Employment_Type`, `Job_Title`, `Salary`, `Salary_Currency`, `Salary_in_USD`, `Employee_Residence`, `Remote_Ratio`, `Company_Location`, `Company_Size`, `Department`, `Education_Level`.

2. **Tableau Dashboard File (`Salary_Analysis_Dashboard.twb`)**
   - Official Tableau Workbook XML linking directly to `salary_analysis_dataset.csv`.
   - Includes 4 KPI Cards, 6 Visual Worksheets, Interactive Slicers, and a unified Dashboard layout.

3. **A4 Dashboard Poster (`A4_Dashboard_Poster.html`)**
   - Printable A4 size (210mm x 297mm) academic poster layout.
   - Includes Student Name, Roll Number, Branch & Semester, Software Used, Project Objective, Dataset Source, Dashboard Layout Visuals, and 6 Key Analytical Insights.

---

## 🚀 How to Use & Submit

### Step 1: Opening in Tableau Desktop / Tableau Public
1. Open **Tableau Desktop** or **Tableau Public**.
2. Click **File -> Open** and select `Salary_Analysis_Dashboard.twb`.
3. If Tableau prompts for data source location, select `salary_analysis_dataset.csv` in this directory.
4. You will see the **Salary Analysis Dashboard** complete with all KPIs, charts, and filter slicers!

### Step 2: Customizing & Exporting the A4 Poster
1. Double click `A4_Dashboard_Poster.html` to open it in Google Chrome, Microsoft Edge, or Firefox.
2. Click directly on **Student Name**, **Roll Number**, or **Branch & Semester** to edit your personal details if needed.
3. Click the top-right **Print / Save as PDF** button (or press `Ctrl + P`).
4. Select **Save as PDF** as destination, set Paper size to **A4**, and save your poster as `Salary_Analysis_Dashboard_Poster.pdf`.
